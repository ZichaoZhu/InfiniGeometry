回答三个问题：两种 SSR 是否在相同样本或区域失败；后续迭代是否破坏已有改善；平均收益是否来自大面积区域而非目标细节。分析结束后提出一项有证据支持的受控实验。

这是 Exp6-4 的结果分析，不新增训练实验。本轮不补第二 seed、不延长训练、不进行 Joint、不替换默认 SSR。复用 seed 173 已完成的两组模型及正式评测。网站保持原选图；test 不用于诊断驱动的调参或方法选择。

## 阶段一：复核输入与逐图分布，CPU 完成

### 1. 配对与一致性

- 按 sample ID 连接两组记录，要求恰好 100 张、无重复、没有只在一组出现的样本。
- 核对配置、checkpoint step、输入哈希、有效像素数、Local mask 来源和两组 K0。记录 `last.pt` 与 `stage1_best.pt` 的区别：当前两组 best step 均为 20,000，但文件 SHA 不同不能单独说明权重不同；主分析始终使用原终点评测及其对应 checkpoint。
- 从原逐图结果重算汇总，确认与已有 summary 在浮点舍入精度内一致。原生 disparity 的训练报告和几何报告来自独立评估，微小重算差异单独记录，不混拼成一份逐图记录。
- 检查无效预测率。出现非有限预测或配对 mask 不一致时先诊断，禁止仅删除坏点后把剩余均值宣称为改善。

### 2. 三组比较

对误差指标，定义第 i 张图的相对 Base 收益与两方法差值：

\[
G_{m,i}=M_{0,i}-M_{m,3,i},\qquad
D_i=M_{\mathrm{official},3,i}-M_{\mathrm{spconv},3,i}.
\]

G 为正表示 SSR 相对 Base 改善；D 为负表示 official_flex 更好。准确率类指标单独标明方向，不套用误差符号。

主要分析 native disparity MAE、Affine Point Rel、Local Point Rel；Depth Rel、Local delta 和 Boundary F1 为辅助解释。每项报告图像宏平均、中位数、差值 10%/90% 分位数、胜/平/负数量，以及最差 5 张的退化幅度。数值平局使用绝对差不超过 1e-6，保留原始差值供核验；该容差不作为实际效果阈值。

按相对共同 K0 的表现分成四类：两组都改善、仅 spconv 改善、仅 official_flex 改善、两组都退化；平局另行计数。同时报告两组退化样本的交集及其占比，检查大收益是否主要集中在少数图片。按 Hypersim scene 分组展示，避免把同一场景的多个视角误认为多个独立场景。

置信区间复用原按场景 bootstrap 结果，不通过反复挑选指标争取显著性。

### 3. 迭代和训练曲线

从逐图指标统计 K0→K1、K1→K3、K3→K5 的变化，重点列出：K1 优于 K0 但 K3 退化；K3 优于 K0 但 K5 退化；K3 已差于 K0 后仍继续变差。分别统计原生 disparity 与几何/Local 指标，防止只在一种指标上过度解释。

逐图最优 K 仅作为事后诊断，不能据此给每张图挑 K 后报告为实际方法效果。

读取两组 full evaluation 曲线及已有 loss/residual 日志，观察最后 5,000 steps 的趋势、是否频繁退化及是否仍在下降。两组 best 均在终点，只说明它们在已评估的检查点中终点最好，不能证明已收敛，也不能直接证明需要延长训练。不同 step 的输入样本不同；同 step 的 A/B 输入虽已配对，仍应比较一段训练区间的趋势，不能只凭某一步的 loss 判断整体效果。

## 阶段二：一次补充推理，定位区域与更新方向

阶段一产出后，两组 checkpoint 各对同一 Val100 推理到 K5，共 200 次图像级前向；使用 eval/no_grad、现有精度、分辨率及数据缓存。一次前向获取 K0 至 K5、raw residual、bounded residual 和 voxel statistics，复用现有接口。此阶段没有反向或 optimizer step。

先各做 2 张预热与验证，测量显存、每图耗时，并与原 K0/K3 MAE 对照；通过后处理完整 Val100。实际耗时据预热后的测量估算，不用训练步耗时推算。

### 1. 区域收益

复用既有 Local segmentation 的非零并集 L；背景区域为有效 mask V 中的补集。逐图报告区域像素占比、区域内 MAE、K3 相对 K0 的改善和退化像素比例，并计算对 full MAE 变化的贡献：

\[
C_{m,R}=\frac{1}{|V|}\sum_{p\in R}
\left(|d^0_p-d_{GT,p}|-|d^3_{m,p}-d_{GT,p}|\right).
\]

对于 R=L 和 R=V\setminus L，要求贡献之和等于该图 full disparity MAE 的改善。由此区分“区域面积大而贡献大”和“每个像素改善幅度大”。

该统计命名为“Local-mask 区域 native disparity 诊断”，不能称为官方 Local Point Rel。正式 Local 仍沿用原 segment 等权及对齐方式；Local 补集也不能直接称为平面。

另外按每图有效 GT radial depth 的三等分分位组统计近/中/远区域，记录真实分位边界；同图所有方法和 K 使用完全相同的分组。它只回答每图相对远近的差异。稀疏或重复深度导致空组时报告为空，不记零分。

边界使用原评测器的同一 GT 深度边界定义，优先复用已有 helper 或可视化输出；记录有效域处理和像素带宽。复用不了时先用原 Boundary F1 与误差图诊断，不临时另造一套“官方边界”算法。

### 2. 更新是否过量、反向或过小

对每次迭代定义：

\[
e^k=d_{GT}-d^k,\qquad u^k=d^{k+1}-d^k.
\]

在相同有效像素上统计：更新方向错误（u 与 e 异号）、跨过 GT（更新前后误差异号）、绝对误差变小/变大、更新幅度和所需修正幅度的分布。跨过 GT 不自动等于变差，两项必须分别判断。

对非零误差像素补充 |u|/|e| 分布，排除 |e|≤1e-6 的不稳定分母并报告排除数量。沿用现有每次迭代 |u|≥0.095 的近限幅比例，分别在全图、Local 区域和近/中/远组汇总。0.1 是单次更新边界，K3 累积更新超过 0.1 不属于越界。

检查 disparity 分位跨度、当前误差与更新幅度的关系，以及 raw residual、voxel span 是否异常。较小 disparity 误差在远处可能对应较大几何误差，但相关性不足以证明 disparity 表达就是根因。

### 3. 固定规则选取诊断图

在阶段一按 Local Point Rel 的 D 排序，分别选择 official_flex 优势最大、spconv 优势最大、差异最接近 0 的各最多 3 张；再从“两组都退化”中按共同退化幅度选择最多 3 张。某类不足时不以相反结论的样本补足。合计最多 12 张，优先每个 scene 一张，去重后保留实际数量，不用 test 补足。

这 12 张用于展示失效模式，不估计总体胜率；所有统计仍用完整 Val100。选图规则与 ID 在补充推理前保存。

每张输出 RGB、GT disparity、共同 K0、两组 K1/K3/K5、相对 GT 的误差图、相对 K0 的有符号收益图和 Local mask 叠加图。相同物理量使用相同色标，差值图以 0 为中心，显示裁剪范围；有效域、视角和 ROI 一致。区域边界通过 mask 或固定规则确定，不能给两方法单独挑不同裁剪。

所有图像统计即时保存，只对选中样本保存绘图所需的密集数组；不新增全量 DINO feature cache 或重导出全部网站 PLY。

## 可选阶段三：只验证一个有证据的机制

只有阶段二发现退化与更新过量一致时，使用现有 `residual_scale` 接口，固定 alpha=0.5 对两组 Val100 各补一次前向，和原 alpha=1 比较。两组使用同一规则，不扫描多个 alpha、不逐图选择 alpha。

缩放每一步 bounded residual 并重新体素化后继续推理，不能把最终 K3 输出线性缩放当作等价实验。输出放独立目录，标记为推理干预诊断，不替换正式终点结果。

该试验只检验这些 checkpoint 对更新幅度是否敏感；即使改善，也不能直接证明重新训练或其他数据上的表现。如果阶段二没有支持该机制，本阶段跳过。

## 决策规则

| 观察证据 | 下一项受控实验方向 | 当前不能直接断言 |
| --- | --- | --- |
| K1 获益后后续退化，像素级过量更新集中，缩步干预也减轻退化 | 固定网络与表达，研究迭代更新幅度/稳定性 | 较小 alpha 是通用最优解 |
| 大部分 full 收益来自 Local 补集，Local 区域不改善或退化 | 固定网络与表达，对监督的区域权重做单变量消融 | 当前 Local masks 覆盖了所有重要细节 |
| 两种网络在相同远处区域失败，disparity 与几何指标明显背离 | 设计 disparity 与其他深度表达的受控比较，明确相应监督尺度 | disparity 已被证明是根因 |
| 两组曲线到终点仍在下降，主要差别呈现为收敛速度 | 再讨论等预算延长或收敛对照 | 20,000 steps 已比较了各自性能上限 |
| official_flex 收益广泛，局部和全局一致且退化有限 | 保留为后续方法候选基线，再单独设计 Base 联合训练对照 | 单 seed 足以全面替换现有实现 |
| 多种证据不一致 | 保留不确定结论，选一个最能区分解释的最小干预 | 强行归因于某一后端或归一化层 |

最终报告只推荐一项优先实验，列出支持证据、反例、待验证假设及需固定的变量。
